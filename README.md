# Obras de arte famosas que han sido atacadas

Prototipo web de la entrega final (reformulación del artículo de BBC News Mundo, 9 oct 2012).

## Ver la página

Abre `index.html` en el navegador o sirve la carpeta con un servidor estático:

```bash
python3 -m http.server 8080
```

Luego visita http://localhost:8080

## Contenido

- Apertura con el caso Rothko (antes / después)
- Índice cronológico con código de color por motivación
- Once fichas con plantilla fija: ficha técnica, imágenes, Qué pasó / Por qué / Qué cambió, cita, estado y navegación entre obras
- Cierre: «¿Destruir o resignificar?»

Autores: Gabriel Rodríguez, Danna García, Alejandra Hernández.
